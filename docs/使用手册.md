## 1. 如何在本地运行 C++

「本地运行」指把编译和运行都放在你自己的浏览器里完成：代码不出本机，断网也能跑，不需要任何服务器。

**第 1 步：下载本地工具链。** 点顶栏的 **本地运行环境** 图标，右侧滑出抽屉。`C++` 一行写着「clang 8 + libc++，约 50MB，只下一次」，点它右侧的 **下载**，等按钮变成 **已就绪**（下载期间按钮下方会播报当前阶段）。

```
本地运行环境抽屉
┌────────────────────────────────────────────┐
│ C++        clang 8 + libc++，约 50MB，只下一次 │ [ 下载 ] → [ 已就绪 ]
│ Python 3   暂未接入本地运行时                 │ [ 下载 ]（不可点）
└────────────────────────────────────────────┘
```

**第 2 步：切换到本地沙箱。** 点顶栏的 **评测引擎设置**（滑杆图标），在「评测引擎」里选 **本地 WASM 沙箱**。它是内置引擎，不需要填服务地址，弹层里会直接提示「本地沙箱在浏览器里跑，不需要服务地址」。

**第 3 步：运行。** 点顶栏绿色的 **▶ 运行全部测试**，或按 `⌘/Ctrl + Enter`。编译与执行都在本机完成，卡片上会给出判定码。

注意事项：

- 只支持 C++。`Python 3` 那行显示「暂未接入本地运行时」，跑 Python 请改用 Piston 或 Judge0（需要联网）。
- 工具链只需下载一次，之后刷新页面会命中缓存，不再重复下载。
- 下载成功过一次后即可离线使用：编辑器、测试面板、本地沙箱都能在断网状态下工作。
- 清除浏览器数据后，缓存会一并清掉，此时第一次编译会重新拉取，慢一些属正常。

## 2. 如何展开 / 折叠样例栏

样例栏就是右侧的 **测试面板**（标题 `Test Cases` 那一栏）。收起它可以把空间让给编辑器，收起后随时能展开回来。

| 方式 | 操作 |
|---|---|
| 双击 | 双击两个区中间的分隔条，收起 / 展开样例栏 |
| 拖到边缘 | 按住分隔条一直往边缘拖，拖到贴边即自动收起 |
| 拖回 | 收起后把分隔条往外拖出 60px，样例栏重新展开 |
| 键盘 | 用 `Tab` 聚焦分隔条，按 `←` / `→` 微调两栏宽度 |
| 触屏 | 分隔条的触摸热区加宽到 24px，手指更好抓 |

```
展开状态                          折叠状态
┌────────────┬─────────────┐      ┌──────────────────────────┐
│  编辑器区   ┃  样例栏      │ ──▶  │        编辑器区           │
└────────────┴─────────────┘      └──────────────────────────┘
             ↑                                    
          分隔条：拖动 / 双击 / 聚焦后 ← → 微调
```

说明：

- 折叠只改变显示与否，测试用例本身不会丢失。
- 拖到贴边才折叠、折叠后要拖出 60px 才展开，两个阈值错开是为了避免停在临界点上反复闪。
- 想让样例栏换到左侧，点顶栏的 **换边** 图标即可。
