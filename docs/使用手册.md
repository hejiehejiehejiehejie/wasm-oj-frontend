只解答两个最常问到的问题。界面里点侧边栏页头的**齿轮图标**打开 **设置** 页签、看 **帮助** 分类，也能看到同一份说明。

## 1. 如何在本地运行 C++

「本地运行」指把编译和运行都放在你自己的浏览器里完成：代码不出本机，断网也能跑，不需要任何服务器。

**第 1 步：下载本地工具链。** 点侧边栏页头的**齿轮图标**打开 **设置** 页签，看左侧目录里的 **本地运行环境**。`C++` 一行写着「clang 8 + libc++，约 50MB，只下一次」，点它右侧的 **下载**，等按钮变成 **已就绪**（下载期间那行会播报当前阶段）。

```
设置 › 本地运行环境
┌──────────────────────────────────────────────────────┐
│ C++        clang 8 + libc++，约 50MB，只下一次           │ [ 下载 ] → [ 已就绪 ]
│ Python 3   CPython 3.11 + 标准库，约 24MB，只下一次      │ [ 下载 ] → [ 已就绪 ]
└──────────────────────────────────────────────────────┘
```

**第 2 步：切换到本地沙箱。** 在设置页签的 **评测** 分类里选 **本地 WASM 沙箱**。它是内置引擎，不需要填服务地址，下方会直接提示「本地沙箱在浏览器里跑，不需要服务地址」。

**第 3 步：运行。** 按 `⌘/Ctrl + Enter`，或点「评测样例」面板页脚那颗 **▶**。编译与执行都在本机完成，卡片上会给出判定码。侧边栏这时会自己展开并切到 **评测样例**——不管你刚才把它收起、还是停在资源管理器上，都能立刻看到结果。

注意事项：

- C++ 与 Python 3 都能走本地运行时（Python 直接解释执行，不需要编译）。跑其它语言请改用 Piston 或 Judge0（需要联网）。
- 工具链只需下载一次，之后刷新页面会命中缓存，不再重复下载。
- 下载成功过一次后即可离线使用：编辑器、侧边栏、本地沙箱都能在断网状态下工作。
- 清除浏览器数据后，缓存会一并清掉，此时第一次编译会重新拉取，慢一些属正常。

## 2. 如何切换侧边栏面板 / 展开 / 折叠侧边栏

侧边栏是一个统一的栏位，页头左侧是三个图标按钮（悬停可见名称）：**资源管理器**（多文件图标）、**评测样例**（带勾清单图标）、**设置**（齿轮图标）。前两颗点一下即切换下面的内容（按钮位置不动，可以连着点）；齿轮则打开编辑器里的**设置**页签，再点一次关掉。整栏可以收起，把空间让给编辑器，收起后随时能展开回来。

| 方式 | 操作 |
|---|---|
| 切换面板 | 点侧边栏页头左侧的「资源管理器」/「评测样例」图标按钮 |
| 打开 / 关闭设置 | 点页头左侧的「设置」齿轮图标（设置在编辑器区域里打开，不占侧边栏） |
| 双击 | 双击两个区中间的分隔条，收起 / 展开整栏 |
| 拖到边缘 | 按住分隔条一直往边缘拖，拖到贴边即自动收起 |
| 拖回 | 收起后把分隔条往外拖出 60px，侧边栏重新展开 |
| 键盘 | 用 `Tab` 聚焦分隔条，按 `←` / `→` 微调两栏宽度 |
| 触屏 | 分隔条的触摸热区加宽到 24px，手指更好抓 |

```
展开状态                          折叠状态
┌────────────┬─────────────┐      ┌──────────────────────────┐
│  编辑器区   ┃  侧边栏      │ ──▶  │        编辑器区           │
└────────────┴─────────────┘      └──────────────────────────┘
             ↑                                    
          分隔条：拖动 / 双击 / 聚焦后 ← → 微调
```

说明：

- 切换页签只改变显示与否，文件树的展开状态与样例里手填的测试数据都不会丢。
- 折叠只改变显示与否，测试用例本身不会丢失。
- 拖到贴边才折叠、折叠后要拖出 60px 才展开，两个阈值错开是为了避免停在临界点上反复闪。
- 想让侧边栏换到左侧，在设置页签的 **布局** 分类里把「侧边栏位置」换成「左侧」。
