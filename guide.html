CPH IDE 使用指南

CPH IDE 是一个在浏览器里写、跑、判 C++ 的在线 IDE：右边是 Monaco 编辑器，左边是测试样例面板。它内置「本地 WASM 沙箱」，编译与运行都在你自己的设备上完成，代码不出本机， 把工具链下载下来之后断网也能用。这份指南覆盖引擎选择、本地运行流程、判定的口径与常见问题。

1. 三种评测引擎

打开顶栏齿轮的「设置」页签，在「评测」分类里可以切换引擎。它们跑代码的位置完全不同，这决定了代码会不会离开你的设备、以及离线时还能不能用。

引擎 在哪里运行 要不要填服务地址 要不要联网
本地 WASM 沙箱 你自己的浏览器（支持 C++ 与 Python 3） 不用，它是内置引擎 首次要下载工具链，之后离线可用
Piston（默认） 你自建的评测服务 要 要
Judge0 你自建的评测服务 要 要

本地沙箱支持 C++ 与 Python 3：C++ 走「编译 + 链接 + 运行」全在浏览器里完成，Python 由 CPython 解释器直接执行，不需要编译。两者的工具链都要先在设置的「本地运行环境」里下载一次。

2. 在本地（浏览器里）编译运行 C++

「本地运行」指把编译和运行都放在你自己的浏览器里完成：代码不出本机，断网也能跑，不需要任何服务器。

  1. 下载本地工具链。打开顶栏齿轮的「设置」页签，看左侧目录里的「本地运行环境」。C++ 一行写着 clang + libc++，约 50MB、只下一次，点它右侧的「下载」，等按钮变成「已就绪」。 已就绪后右侧会多出一颗「卸载」，点它会先弹确认框，确认后清掉本机缓存，下次运行再重新下载。
  2. 切换到本地沙箱。在设置页签的「评测」分类里选「本地 WASM 沙箱」。它是内置引擎， 不需要填服务地址。
  3. 运行。按 ⌘/Ctrl + Enter，或点右侧「评测样例」面板页脚那颗 ▶。 编译与执行都在本机完成，卡片上会给出判定码。
  • 工具链只需下载一次，之后刷新页面会命中浏览器缓存，不再重复下载。
  • 下载成功过一次之后即可离线使用：编辑器、测试面板、本地沙箱在断网状态下都能工作。
  • 清除浏览器数据会把缓存一并清掉，此时第一次编译要重新拉取工具链，慢一些属正常。

3. 测试样例与时限判定

右侧的「测试面板」就是样例栏，每个样例一张卡片：上面是输入框，下面是程序输出的只读块。用面板底部的「添加测试样例」增加用例， 卡片头右侧的按钮可以删除或折叠单个用例。跑完每张卡片会显示一个判定码。

判定码 含义
AC 程序正常结束，且输出与期望输出一致
WA 程序正常结束，但输出与期望输出不一致
CE 编译失败（编译错误）
TLE 运行时间超过当前时限
RE 运行时错误，程序非正常退出
ERR 评测服务连不上之类的环境问题，不是你的代码有问题

时限与耗时的口径

  • 面板页头的「时限」（1 / 2 / 5 / 10 秒，默认 1 秒）只计程序运行那一段，不含编译时间。 超时靠终止当前运行的沙箱实例实现。
  • 卡片上的耗时和时限是同一个口径，也只算程序运行段。程序没跑起来时（比如编译失败）卡片不显示耗时。
  • 面板页头显示的是当轮所有用例里最慢的那个的耗时。

4. 编辑器与界面偏好

打开顶栏齿轮的「设置」页签：在「外观」分类里可以调整套界面的主题（深色 / 浅色）、字号与界面缩放；在「编辑器」分类里可以调字体、缩进宽度、自动换行、小地图等。 这些设置与代码草稿、测试样例、两栏比例一样，都存在你浏览器的本地存储里，换台设备不会跟着走。

样例栏的展开与折叠

方式 操作
双击 双击两栏中间的分隔条，收起 / 展开样例栏
拖到边缘 按住分隔条一直往边缘拖，拖到贴边即自动收起
拖回 收起后把分隔条往外拖出，样例栏重新展开
键盘 用 Tab 聚焦分隔条，按 ← / → 微调两栏宽度
触屏 分隔条的触摸热区会加宽，手指更好抓

折叠只是不显示，测试用例本身不会丢。想让样例栏换到右侧，在设置页签的「外观」分类里把「侧边栏位置」换成「右侧」。

5. 安装到设备、离线使用

CPH IDE 可以当作一个独立窗口的应用安装到电脑或手机上。浏览器判定当前站点可以安装时，顶栏会出现「安装」按钮， 点它按提示确认即可；装好之后按钮会自动消失，再从桌面图标打开就是独立窗口，没有地址栏。

  • iPhone / iPad 上的 Safari 没有这个按钮，需要手动走「分享 → 添加到主屏幕」。
  • 安装后浏览器会缓存界面外壳和本地工具链，断网状态下编辑器、测试面板与本地沙箱都照常工作。
  • 离线时只有 Piston 与 Judge0 这两种远端引擎会失效，因为它们需要联网。

6. 常见问题

代码会上传到服务器吗？

用本地 WASM 沙箱时不会：编译与运行都在你自己的浏览器里完成，代码不离开这台设备。切到 Piston 或 Judge0 这类远端引擎时，代码会发送到你填写的评测服务地址。

需要联网吗？

第一次用本地沙箱要先下载约 50MB 的 C++ 工具链，只下一次，之后常驻浏览器缓存。下载过之后即可离线使用； 清除了浏览器数据就要重新下载。

支持哪些语言？

本地 WASM 沙箱支持 C++ 与 Python 3。其它语言要切到 Piston 或 Judge0 远端评测服务，具体支持范围取决于你所连的服务。

为什么第一次运行明显更慢？

首次运行要先下载工具链；之后每一份新代码的第一个用例都要付一次编译开销，同一份代码连续跑多个用例只编译一次， 第 2 个起只付运行开销。另外后台会在这台设备上生成一份 STL 预编译头，用来省掉每次编译反复解析标准库头的开销， 它安排在首次运行之后的空闲时间进行，不阻塞操作，失败也不影响正常编译。

为什么耗时和别的评测服务对不上？

这里的耗时只计程序运行段，不含编译与排队，所以看起来会比按总耗时统计的平台小。不同引擎和不同设备之间也不适合直接比较。

数据存在哪里？

代码草稿、测试样例、编辑器偏好、两栏比例这类状态存在浏览器的 localStorage 里；本地工具链的预编译头存在 IndexedDB 里。它们都只在这台设备的这个浏览器里，清除浏览器数据会一并清掉。
