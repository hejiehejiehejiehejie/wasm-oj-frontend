隐私政策

本政策适用于本站 unnamed（www.998244353.best）与浏览器扩展 CC for Web。最后更新：2026-10-06。

一句话总结

本站没有账号体系，你的代码、题目与手写测试用例都只存在你自己的浏览器里，不会上传到我们的服务器。 唯一会上传的是你主动点击「上传本机设置」的那份偏好配置，而且它是公开可读的。

站点在你的浏览器本地保存什么

下列数据都只在这台设备的这个浏览器里，本站无法读取，也没有副本：

  • 编辑器偏好（主题、快捷键、界面缩放、侧边栏位置与两栏比例、运行时限）——存在浏览器的 localStorage 里。
  • 文件树与文件正文（你的题目、代码、题解）——存在浏览器的 IndexedDB 里。
  • 预编译头等缓存——同样在 IndexedDB 里。

清除浏览器数据会把这些一并清掉。我们没有任何途径把它们取回。

可选的云端同步

只有你主动点击「上传本机设置」时才会发生，上传的只有偏好类项： 主题、快捷键、界面缩放、侧边栏位置、两栏比例、运行时限。

上传之后这份配置是公开可读的：任何人不需要登录，只要知道你的 Codeforces 用户名， 就能通过形如 https://www.998244353.best/用户名 的地址取到同一份配置。 所以点「上传本机设置」就等于同意公开这份配置。

判题服务器地址、手写测试用例、文件树与文件正文都不会上传。 若你希望删除已上传的配置，见文末联系方式。

代码什么时候会离开你的设备

只有两种情况，且都由你主动触发：

  • 切换到外部评测服务时。当你把评测引擎切到 Piston 或 Judge0， 代码会被发送到你自己填写的那个服务地址。那是你自己的部署，数据处理方式由你决定， 本站不经手、也不留存。
  • 使用浏览器扩展抓题时。扩展读取当前题目页，把题面与样例投递给你指定的接收端 （本机运行的工具，或你自己正在使用的本站编辑器），不经过我们的服务器。

使用内置的本地 WASM 沙箱时，代码始终留在你的设备上。

浏览器扩展会读取什么

  • 只在你点击扩展图标或按下快捷键时，读取当前标签页的网址，用来判断这个页面是否受支持。
  • 在受支持的题目站点上，读取该页面的题面与样例文本。
  • 不读取其它标签页，不记录浏览历史，不采集任何个人身份信息。
  • 解析结果只发送到你自己选择的目标，不经过我们的服务器。

我们不做什么

  • 不收集姓名、邮箱、手机号等个人身份信息，本站也不需要注册。
  • 不做广告，不做埋点统计，不做用户画像。
  • 不出售、不出租、不共享任何数据给第三方。
  • 不在你不知情的情况下上传任何文件。

第三方服务

  • 本站通过 Vercel 托管、Cloudflare 分发静态资源；访问日志由这两家服务商按各自的隐私政策处理，我们不做额外留存。
  • 代码区内置的三款开源等宽字体（JetBrains Mono / Fira Code / Cascadia Code）只在你于「设置 › 编辑器 › 字体」里选中时才下载。
  • 完整组件与许可证清单见第三方开源组件与许可。

儿童

本站不面向 13 岁以下儿童，也不会在知情的情况下收集其个人信息。

政策变更
